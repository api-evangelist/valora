# Valora

> Valora is an open-source, self-custodial mobile crypto wallet (Celo-born, now multichain across Celo, Ethereum, Arbitrum, Optimism, Base, and Polygon) from Valora Inc (a16z and Polychain backed). Its public, unauthenticated HTTP API serves token metadata and prices, swap quotes, NFTs, and transaction simulation, and its Divvi Hooks platform lets developers extend the app with position-pricing and shortcut hooks. Mutating flows never custody funds: they return unsigned transactions the wallet signs client-side.

Generated by API Evangelist from the valora company profile and repo artifacts (2026-07-21). Valora publishes no llms.txt of its own (probed /llms.txt: 404).
